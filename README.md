# 🚀 GitNexus


GitNexus is a modern blogging platform where users can share blogs, explore Git commands, and learn about DevOps concepts like AWS and CI/CD pipelines.  
This project is built with **HTML, CSS (Bootstrap), JavaScript, and GSAP**.

---

## 🌟 Features
- 📝 Blog posting with auto-slider
- 👤 Profile card section (Name, Role, Portfolio)
- 🎨 Animated navbar with GSAP
- 🔐 Register form (redirects to Google Form)
- ☁️ Basic AWS + CI/CD learning section

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS (Bootstrap), JavaScript
- **Animations:** GSAP
- **Deployment:** AWS
- **Version Control:** Git & GitHub
